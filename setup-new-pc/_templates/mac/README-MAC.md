# Подключение к серверу Codex — для __DISP__ (macOS)

Эта папка настраивает ваш Mac, чтобы из программы VSCode подключаться к серверу и
работать с Codex. Делается один раз. Ваш логин на сервере: **__USER__**.

В папке лежит ваш **личный** ключ доступа — он только ваш, никому не передавайте.

---

## Шаг 1. Установите VSCode и расширение Remote-SSH

1. Откройте **https://code.visualstudio.com/** → **Download for macOS**.
2. Откройте скачанный файл и перетащите значок **Visual Studio Code** в папку
   **«Программы» (Applications)**. Запустите VSCode оттуда.
3. Внутри VSCode слева нажмите значок **Extensions** (четыре квадратика).
   В поиске напечатайте **`Remote - SSH`** и у расширения от **Microsoft** нажмите
   **Install**.

---

## Шаг 2. Скопируйте эту папку на компьютер

Скопируйте эту папку (со всем содержимым) на этот Mac — например, в
**«Загрузки» (Downloads)**.

> ⚠️ Внутри лежит файл-ключ — это как пароль от сервера. Никому не пересылайте.

---

## Шаг 3. Запустите настройку — НАДЁЖНЫЙ способ (через Терминал)

Этот способ работает всегда и не упирается в защиту macOS.

1. Откройте **Терминал**: **Cmd + Пробел**, напечатайте `Терминал` (или `Terminal`),
   нажмите **Enter**.
2. Напечатайте слово `bash` и **один пробел** после него (Enter пока не нажимайте):
   ```
   bash 
   ```
3. Откройте в Finder эту папку и **перетащите мышкой файл `setup-mac.sh`** прямо в
   окно Терминала — путь подставится сам.
4. Нажмите **Enter**.

Дождитесь строки:

```
OK_CONNECTED as __USER__
```

Это значит — всё настроено. Окно можно закрыть.

---

## Шаг 3 (альтернатива). Двойной клик по `УСТАНОВКА.command`

Можно попробовать дважды кликнуть **`УСТАНОВКА.command`**. macOS, скорее всего,
заблокирует запуск «от неизвестного разработчика». Если так:

- **Вариант 1:** правый клик (или Ctrl+клик) по файлу → **«Открыть»** → в окне
  предупреждения снова **«Открыть»**.
- **Вариант 2:** **Системные настройки → Конфиденциальность и безопасность**,
  пролистайте вниз → кнопка **«Всё равно открыть» (Open Anyway)**.

Если не помогает — используйте надёжный способ через Терминал (выше).

---

## Шаг 4. Подключитесь к серверу из VSCode

> 💡 **Важно при первом подключении:**
> - Выбирайте `codex-server` **из списка** — НЕ используйте «+ Add New SSH Host»
>   (это может испортить настройки и подключение перестанет работать).
> - Если появится окно **«Select the platform of the remote host»** — выберите **Linux**.
> - Спросит про отпечаток (fingerprint) — нажмите **Continue**.
> - Первое подключение длится **1–2 минуты** (ставится VS Code Server) — это нормально, не закрывайте.


1. Откройте **VSCode**.
2. **Cmd + Shift + P** → напечатайте `Remote-SSH` → **Remote-SSH: Connect to Host...**
   > ⚠️ **Нет пункта «Remote-SSH: Connect to Host»?** Установите расширение: слева значок
   > **Extensions** (`Cmd+Shift+X`) → поиск **`Remote - SSH`** → у расширения **Microsoft**
   > нажмите **Install**, затем повторите.
3. Выберите **`codex-server`**.
4. Внизу слева появится зелёная плашка **`SSH: codex-server`** — вы подключены.

---

## Шаг 5. Создайте или откройте папку проекта

Все проекты держите внутри `~/projects` — отдельная папка на каждый проект.

**Создать новый проект:** откройте терминал (**Terminal → New Terminal**) и:
```bash
cd ~/projects
mkdir мой-проект
```

**Открыть проект в VSCode:** меню **File → Open Folder...** → введите путь
`/home/__USER__/projects/мой-проект` → **OK**. Если спросят про доверие —
**Yes, I trust the authors**.

> 📁 **Не видно список файлов?** Нажмите **`Cmd+Shift+E`** — откроется панель
> **Explorer** с файлами. Если скрыта вся боковая панель — **`Cmd+B`**.
> Перенести панель вправо: меню **View → Appearance → Move Primary Side Bar Right**.

> Открывайте именно папку проекта (а не общий `projects`) — так Codex видит только
> её файлы и не путается в чужих.

**Готовый репозиторий с GitHub:**
```bash
cd ~/projects
git clone АДРЕС_РЕПОЗИТОРИЯ
```
затем откройте склонированную папку через **Open Folder**.

## Шаг 6. Запустите Codex — два способа

### Способ А — панель Codex (удобно, как чат) — рекомендуется
1. Установите расширение (один раз): в терминале VSCode выполните
   ```bash
   code --install-extension openai.chatgpt
   ```
   затем `Cmd+Shift+P` → **Developer: Reload Window**.
2. Слева на панели значков появится значок **Codex** — кликните по нему.
   *(Если значка не видно: `Cmd+Shift+P` → наберите **Codex** → команда откроет
   панель; либо в списке расширений перетащите значок Codex на левую панель.)*
3. Если попросит войти — **Sign in with ChatGPT** (вход уже настроен на сервере).
4. Если спросит режим — выберите **Agent** (правит файлы и запускает команды,
   спрашивает перед важными действиями).
5. В поле **«Ask Codex to do anything»** пишите задачи обычным текстом. Через `@`
   можно подставить файл: «@index.php найди и исправь ошибку».

### Способ Б — в терминале
В терминале VSCode (в папке проекта) напечатайте `codex` и **Enter** — запустится
тот же агент в текстовом режиме. Разовая задача: `codex exec "напиши README"`.

---

## Шаг 7. Длинные задачи без обрыва (tmux)

Чтобы Codex в терминале продолжал работать, даже если закрыть ноутбук: напечатайте
`tm` — откроется фоновая сессия, внутри запустите `codex`. Выйти, не прерывая работу:
**Ctrl+b**, затем **d**. Вернуться позже — снова `tm`.

---

## Шаг 8. Как поставить инструменты самому (без админа)

Всё нужное для разработки ставится **в вашем профиле, без прав администратора** —
прямо в терминале сервера (в подключённом VSCode).

**PHP — PHPStan / PHPUnit в проект:**
```bash
composer require --dev phpstan/phpstan phpunit/phpunit
./vendor/bin/phpstan analyse
./vendor/bin/phpunit
```
(или пользуйтесь системными — они уже стоят: `phpstan`, `phpunit`)

**Python — pytest и любые pip-пакеты (через виртуальное окружение):**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install pytest
```

**Node — глобальные npm-пакеты (ставятся в ваш профиль `~/.npm-global`):**
```bash
npm install -g <название-пакета>
```

**Codex-агент** запускается командой `codex` в любой папке проекта.

> Требует администратора только установка **системных** пакетов (`apt`) — например,
> новое расширение PHP. В этом случае напишите администратору сервера.

## Если что-то пошло не так

**Нет строки `OK_CONNECTED as __USER__`:** повторите Шаг 3 (через Терминал).

**Пишет, что не найден файл ключа:** перетащили скрипт не из той папки —
перетаскивайте `setup-mac.sh` из вашей папки, где лежит и файл ключа.

**Просит пароль / `Permission denied`:** выполните в Терминале и повторите Шаг 3:
```bash
chmod 700 ~/.ssh && chmod 600 ~/.ssh/__KEYNAME__
```

**Нет Remote-SSH / расширение не ставится:** обновите VSCode до последней версии
(**Code → Check for Updates**) — на старых ставится плохо; затем Extensions
(`Cmd+Shift+X`) → `Remote - SSH` → **Install** (Microsoft) → перезапустите VSCode.

Если не получается — пришлите скриншот окна Терминала тому, кто выдал вам папку.
