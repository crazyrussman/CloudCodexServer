# Подключение к серверу Codex — для __DISP__ (Windows)

Эта папка настраивает компьютер на Windows, чтобы из программы VSCode подключаться
к серверу и работать с Codex. Делается один раз. Знаний администрирования не нужно —
просто следуйте шагам по порядку. Ваш логин на сервере: **__USER__**.

В папке лежит ваш **личный** ключ доступа — он только ваш, никому не передавайте.

---

## Шаг 1. Установите VSCode (если ещё нет)

1. Откройте сайт: **https://code.visualstudio.com/**
2. Нажмите синюю кнопку **Download for Windows**.
3. Запустите скачанный файл и устанавливайте, нажимая **«Далее / Next»** до конца.

> Если VSCode уже установлен — пропустите этот шаг.

---

## Шаг 2. Скопируйте эту папку на компьютер

Скопируйте эту папку (со всем содержимым) на компьютер — например, на **Рабочий стол**.

> ⚠️ Внутри лежит файл-ключ — это как пароль от сервера. Никому не пересылайте.

---

## Шаг 3. Запустите настройку (один двойной клик)

1. Откройте скопированную папку.
2. Найдите файл **`УСТАНОВКА`** (тип — «Пакетный файл Windows»).
3. **Дважды кликните** по нему.
4. Откроется чёрное окно — нажмите любую клавишу, когда попросит.
5. Если выскочит синее окно **«Система Windows защитила ваш компьютер»** —
   нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**.
6. Если Windows спросит разрешение — нажмите **«Да»**.

Дождитесь строки:

```
OK_CONNECTED as __USER__
```

Это значит — всё настроено. Закройте окно.

---

## Шаг 4. Подключитесь к серверу из VSCode

> 💡 **Важно при первом подключении:**
> - Выбирайте `codex-server` **из списка** — НЕ используйте «+ Add New SSH Host»
>   (это может испортить настройки и подключение перестанет работать).
> - Если появится окно **«Select the platform of the remote host»** — выберите **Linux**.
> - Спросит про отпечаток (fingerprint) — нажмите **Continue**.
> - Первое подключение длится **1–2 минуты** (ставится VS Code Server) — это нормально, не закрывайте.


1. Откройте **VSCode**.
2. Нажмите на клавиатуре **F1**.
3. Напечатайте `Remote-SSH` и выберите **Remote-SSH: Connect to Host...**
   > ⚠️ **Нет пункта «Remote-SSH: Connect to Host» в списке?** Значит не установлено
   > расширение. Слева нажмите значок **Extensions** (`Ctrl+Shift+X`) → в поиске
   > напечатайте **`Remote - SSH`** → у расширения от **Microsoft** нажмите **Install**.
   > Затем повторите пункт 2.
4. Выберите **`codex-server`**.
5. Откроется новое окно. Внизу слева появится зелёная плашка **`SSH: codex-server`** —
   вы подключены. (Первый раз пара минут на подготовку — это нормально.)

---

## Шаг 5. Создайте или откройте папку проекта

Все проекты держите внутри `~/projects` — отдельная папка на каждый проект.

**Создать новый проект:** откройте терминал (**Terminal → New Terminal**) и:
```bash
cd ~/projects
mkdir мой-проект
```

**Открыть проект в VSCode:** меню **File → Open Folder...** → введите путь
`/home/__USER__/projects/мой-проект` → **OK**. Если спросят про доверие —
**Yes, I trust the authors**.

> 📁 **Не видно список файлов?** Нажмите **`Ctrl+Shift+E`** — откроется панель
> **Explorer** с файлами. Если скрыта вся боковая панель — **`Ctrl+B`**.
> Перенести панель вправо: меню **View → Appearance → Move Primary Side Bar Right**.

> Открывайте именно папку проекта (а не общий `projects`) — так Codex видит только
> её файлы и не путается в чужих.

**Готовый репозиторий с GitHub:**
```bash
cd ~/projects
git clone АДРЕС_РЕПОЗИТОРИЯ
```
затем откройте склонированную папку через **Open Folder**.

## Шаг 6. Запустите Codex — два способа

### Способ А — панель Codex (удобно, как чат) — рекомендуется
1. Установите расширение (один раз): в терминале VSCode выполните
   ```bash
   code --install-extension openai.chatgpt
   ```
   затем `F1` → **Developer: Reload Window**.
2. Слева на панели значков появится значок **Codex** — кликните по нему.
   *(Если значка не видно: `F1` → наберите **Codex** → команда откроет панель;
   либо в списке расширений перетащите значок Codex на левую панель.)*
3. Если попросит войти — **Sign in with ChatGPT** (вход уже настроен на сервере).
4. Если спросит режим — выберите **Agent** (правит файлы и запускает команды,
   спрашивает перед важными действиями).
5. В поле **«Ask Codex to do anything»** пишите задачи обычным текстом. Через `@`
   можно подставить файл: «@index.php найди и исправь ошибку».

### Способ Б — в терминале
В терминале VSCode (в папке проекта) напечатайте `codex` и **Enter** — запустится
тот же агент в текстовом режиме. Разовая задача: `codex exec "напиши README"`.

---

## Шаг 7. Длинные задачи без обрыва (tmux)

Чтобы Codex в терминале продолжал работать, даже если закрыть ноутбук: напечатайте
`tm` — откроется фоновая сессия, внутри запустите `codex`. Выйти, не прерывая работу:
**Ctrl+b**, затем **d**. Вернуться позже — снова `tm`.

---

## Шаг 8. Как поставить инструменты самому (без админа)

Всё нужное для разработки ставится **в вашем профиле, без прав администратора** —
прямо в терминале сервера (в подключённом VSCode).

**PHP — PHPStan / PHPUnit в проект:**
```bash
composer require --dev phpstan/phpstan phpunit/phpunit
./vendor/bin/phpstan analyse
./vendor/bin/phpunit
```
(или пользуйтесь системными — они уже стоят: `phpstan`, `phpunit`)

**Python — pytest и любые pip-пакеты (через виртуальное окружение):**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install pytest
```

**Node — глобальные npm-пакеты (ставятся в ваш профиль `~/.npm-global`):**
```bash
npm install -g <название-пакета>
```

**Codex-агент** запускается командой `codex` в любой папке проекта.

> Требует администратора только установка **системных** пакетов (`apt`) — например,
> новое расширение PHP. В этом случае напишите администратору сервера.

## После установки — удалите эту папку

Ключ уже скопирован в `C:\Users\<вы>\.ssh\` — установка больше не нужна.
Оставшаяся папка (и письмо/архив, из которого вы её взяли) — это **второй
экземпляр пароля от сервера**. Удалите её из Загрузок, из почты и с флешки.

## Если что-то пошло не так

**Нет строки `OK_CONNECTED as __USER__`:** запустите `УСТАНОВКА` ещё раз.

**Просит пароль / `Permission denied`:** запустите `УСТАНОВКА` повторно.

**Команда `ssh` не найдена:** Параметры Windows → Приложения → Дополнительные
компоненты → Добавить → **«Клиент OpenSSH»**, затем снова `УСТАНОВКА`.

**В VSCode нет Remote-SSH / расширение не ставится:**
1. **Обновите VSCode** до последней версии (на старых версиях расширения ставятся
   плохо): меню **Help → Check for Updates**, либо переустановите с
   https://code.visualstudio.com. Перед запуском `УСТАНОВКА` **закройте VSCode**.
2. Поставьте расширение вручную: значок «кубиков» (Extensions, `Ctrl+Shift+X`) →
   поиск `Remote - SSH` → **Install** у расширения **Microsoft** → `F1` →
   **Developer: Reload Window**.

Если не получается — пришлите скриншот ошибки тому, кто выдал вам эту папку.
